# Дельта — демо проверки контрагентов

Публичная ссылка: https://neurotatarin.github.io/delta-counterparty-demo/

Интерактивный макет интерфейса, стилизованный под Telegram Mini App. Данные компаний, баллы и события вымышлены. Подключений к 1С и СБИС нет.

## Что показывает демо

Макет показывает, как карточки контрагентов и изменения статусов могут выглядеть в одном интерфейсе. Интеграции и правила оценки рисков для конкретной компании требуют отдельного проектирования.

## Обновление демо

- Исходный файл страницы — `index.html` в ветке `main`.
- GitHub Pages уже настроен на публикацию из `main`, каталог `/ (root)`.
- После обновления `index.html` GitHub автоматически запускает `pages-build-deployment`. Статус виден во вкладке Actions.
- Проверьте опубликованную ссылку и основные переходы после завершения развёртывания.

Для следующих правок файла достаточно подключённого GitHub-плагина. Вход в браузер нужен лишь для настроек репозитория, которые плагин не поддерживает.
